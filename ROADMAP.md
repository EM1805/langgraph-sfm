# Roadmap

## 0.1.x

- Stabilize `SFMIntentAnalyzerNode` and `SFMAgentMonitor` APIs.
- Add more public examples for ReAct-style agents and tool-calling workflows.
- Add LangSmith trace-enrichment example.

## 0.2.x

- Add adapters for persisted LangGraph traces.
- Add richer run reports and optional markdown/HTML summaries.
- Add external validation fixtures from real agent traces when available.

## Research track

- Domain-owned SCM/DAG validation.
- Negative-control libraries for common agent tasks.
- Adversarial trace suites for hidden-goal and side-effect scenarios.
